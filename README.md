# CamoFA

Project website for **CamoFA: A Learnable Fourier-based Augmentation for Camouflage Segmentation** (WACV 2025).

Live site: https://minhquanlecs.github.io/camofa/

## Editing and deployment

Edit `index.html` and assets in `static/`, then commit and push to `main`. GitHub Pages publishes the repository root from `main`. The `.nojekyll` file serves the static files directly.

To preview locally, run `python3 -m http.server 8000` from this directory and open http://localhost:8000/.

The original website template attribution and license notice are retained in the page footer.
